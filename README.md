# No Moss Spreading
## About
A simple mod that adds two gamerules to stop grass and moss from spreading.
I am pretty sure this mod has been already done by someone else.

## Features
- doMossSpread to stop moss from spreading, by default true
- doGrassSpread to stop grass from spreading, by default true

## Recommendation
If you want to use tons of mossy stone but keep spreading disabled I would recommend using 
my datapack:
https://drive.google.com/file/d/1prXrd5_4hoY6_j8My5sfrahTZkr4IymF/view?usp=sharing
All mossy and moss block variants can now be crafted using algae.
